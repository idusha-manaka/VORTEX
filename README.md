**Vortex** is a premium, futuristic web application designed to experiment with device physics. By utilizing high-frequency vibration patterns, Vortex attempts to overcome surface friction to rotate a mobile device 360 degrees.

---

## ✨ Features

- **🚀 Multiple Vibration Modes**:
    - `Continuous`: Steady torque for sustained rotation.
    - `Rapid Pulse`: High-frequency bursts to break static friction.
    - `Vortex Sync`: A custom rhythmic sequence for optimized spinning.
    - `Stand Mode`: Micro-vibrations designed for vertical stability (Samsung A16 optimized).
- **🎨 Premium Aesthetics**: Dark-mode futuristic UI with glassmorphism and glowing visualizers.
- **📱 PWA Ready**: Install it as a standalone app on your Android or iOS device.
- **🔋 Energy Efficient**: Automatically halts vibration when the tab is hidden or minimized.
- **🌐 Offline Support**: Works seamlessly without an internet connection once installed.

---

## 🛠️ How to Use

1. **Visit the Site**: Open the Vercel link on your mobile browser (Chrome/Samsung Internet recommended).
2. **Prepare Surface**: Place your phone on a **smooth, flat, and level surface** (e.g., Glass, Polished Marble).
3. **Select Mode**: Choose your preferred vibration pattern.
4. **Ignite**: Tap the **IGNITE VORTEX** button and watch the physics in action!

> [!IMPORTANT]
> **Pro Tip**: Remove your phone cover for the best results. The friction from rubber/silicone covers often prevents rotation.

---

## 🏗️ Technical Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3.
- **APIs**: Web Vibration API (`navigator.vibrate`).
- **Standard**: PWA (Service Workers, Web Manifest).
- **Deployment**: Optimized for Vercel.
